# Setup (10 minute)
1. github.com par free account banayein, naya **public repo** banayein, is folder ki saari files upload karein.
2. Repo > Settings > Pages > Source: "Deploy from branch" > main / root. Aapka link: https://USERNAME.github.io/REPO/
3. Repo > Actions tab > "Update opportunities" > "Run workflow" (pehli baar khud chalayein). Uske baad roz khud chalega.
4. (Optional) ReliefWeb jobs ke liye reliefweb.int/help/api se appname approve karwayein, phir Settings > Secrets > Actions mein RELIEFWEB_APPNAME daalein.
5. Phone mein link Chrome mein kholein > menu > "Install app".
Scholarships mein jab official page badle to app mein "⚠ changed" nishan aayega; data/scholarships.json mein check karke update karein.
